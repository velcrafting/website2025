## Discovery questions

- What should a user accomplish, and how is that task handled today?
- Which journeys are essential for this engagement? Which can wait?
- What existing repository, design system, integrations and infrastructure constrain the work?
- What data and stakeholder roles are involved? Who owns each dependency?
- Which behaviors can use illustrative data, and which require a real integration?
- Who will maintain, operate and approve release of the result?
- What would cause the client to reject the handoff despite a successful demonstration?

Add production operating checks only when production delivery is in scope.
